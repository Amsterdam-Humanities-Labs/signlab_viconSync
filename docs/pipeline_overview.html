Vicon mocap stream
SSH/SCP SyncPython · via PythonCrondaily 02:30 (120 min timeout) Pulls FBX/GLB, LiveLink CSV, metadata JSON and Shogun MOV/MCP/ENF/X2D files from the Vicon PC (E:\Recordings, D:\PostExports) into /web/gebarenoverleg_media/. Smart size-based change detection.
FBX→GLB ConverterNode.js Express · fbx2glb-server.serviceHTTP :3016 · batch hourly Converts FBX mocap files to GLB for web 3D viewing — on demand via HTTP API, plus an hourly batch pass (fbx2glb-batch.service).
GLB MatcherPython + MySQLafter sync · 300 s poll Pairs each FBX with its converted GLB in the media directory and writes glb_path into the vicon_files table so the dashboard can link 3D previews.
Vicon File MatcherPython · via PythonCrondaily 23:00 Matches synced FBX/CSV files against mocap_files database records using filename patterns, associating capture files with their mocap sessions.
File CleanupPython + SSH + rclone · via PythonCronweekly 04:00 Confirms files are safely stored locally and on the SharePoint archive, then deletes them from the Vicon PC (OBS recordings, Shogun captures) to free space.
Resync UtilityPython · manual CLIon demand Recovery tool: re-downloads specific FBX files from the Vicon FTP based on the contents of fbx/post_processed/.
Studio capture stream
Sony SDK Camera ServerNode.js · systemd:8080 HTTP · :8081 WS Controls Sony studio cameras and receives their video streams, storing footage under studioFiles/ and serving media to web/Unreal clients.
LiveLink Upload ServerNode.js + multer · llserver.service:3031 HTTP upload endpoint for studio capture systems; accepts LiveLink CSV/video files up to 500 MB into studioFiles/llTakes/ with auto-timestamping on name conflicts.
LiveLink Video ConverterPython + ffmpeg · via PythonCrondaily 22:00 (90 min timeout) Batch-converts studio MOV recordings to MP4 in llVideos/ and copies the matching raw CSV data into llcsv/.
Real-time stream
FTP MonitorPython · systemdcontinuous · 1.5 s poll Watches the Vicon FTP for new recording files the moment they appear, categorizes them by type, groups them per capture session, and writes vicon_captures / vicon_files rows. Also emits monitor_output.json for live views.
DB WriterPython module (pymysql)used by FTP Monitor Database abstraction layer handling all MySQL writes of capture metadata and file records into admin_gebarenoverleg.
Unreal WebSocket ServerNode.js (ws) · systemd:3008 WS Real-time bidirectional bridge with Unreal Engine: streams mocap data, synchronizes animations, drives live avatars.
Data & UI
MySQLMySQL Server · mysql.service:3306 Source of truth (database admin_gebarenoverleg): vicon_captures, vicon_files, vicon_monitor_metadata and mocap_files tables feed the dashboard.
Vicon DashboardPHP APIs + vanilla JS · Apache + PHP-FPM:80 / :443 Web UI showing captures grouped by date, file types and counts, GLB preview links, and overall system status; auto-refreshes every 30 s from MySQL and the filesystem.
